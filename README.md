# UABiz / UABissGame

Однопользовательский экономический симулятор: розница, производство, исследования,
логистика, кредиты, фондовый рынок и пять глав развития компании. Приложение
работает целиком в браузере; сервер приложения и сборка не требуются.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000`. Chart.js 4.5.1 включён в `js/vendor`,
лицензия находится рядом. Интернет для игровых механик не нужен.

## Сохранение

Прогресс автоматически сохраняется в localStorage текущего браузера после
действий и успешного закрытия дня. Меню «Сохранение» позволяет экспортировать
JSON, импортировать его и начать новую игру. Перед заменой сохраняется резервная
копия в `uabiz_save_v1_backup`. Повреждённые или неподдерживаемые сохранения
отклоняются, исходный файл/запись сохраняется.

Хранилище привязано к адресу приложения. Для переноса между браузерами или
адресами используйте экспорт/импорт. Очистка данных сайта удаляет localStorage.

## Проверки

Для тестов игровой логики нужен Node.js 22 или новее; зависимости не требуются:

```sh
node --test tests/*.test.cjs
```

Набор проверяет запасы, маршруты, доставки, бухгалтерию, банк, персонал, науку,
тендеры, сохранения и воспроизводимые сценарии торговли на 30/90/365 дней.

Браузерные проверки необязательны. Установите Playwright в отдельную директорию,
чтобы не менять зависимости статического приложения:

```sh
npm install --prefix /tmp/uabiz-browser-tests playwright@1.58.2
/tmp/uabiz-browser-tests/node_modules/.bin/playwright install chromium
NODE_PATH=/tmp/uabiz-browser-tests/node_modules node tests/browser.cjs
```

Статический сервер должен работать на порту 8000. Другой адрес задаётся через
`GAME_URL`; установленный Chromium можно выбрать через `CHROMIUM_PATH`.
Проверяются 14 вкладок на трёх ширинах, сохранение после перезагрузки,
финансовые экраны, сохранение ввода, управление с клавиатуры и полный курс до
первой продажи.

## Устройство

- `js/data`: ресурсы, рецепты, региональные коэффициенты.
- `js/core`: состояние, проверка/сохранение, общие операции с запасами, цикл дня.
- `js/managers`: игровые механики и отдельный учёт прибыли и денежных потоков.
- `js/ui`: вкладки, уведомления, обучение, справочник, доступность.
- `tests`: проверки без сборки приложения.

Капитализация рассчитывается единым методом `FINANCE.getAssetsBreakdown()`.
Закупки и доставка капитализируются в себестоимости запасов; она списывается
при продаже. Денежные операции проходят через `LEDGER.cash()`.
Закрытие дня восстанавливает предыдущее состояние при ошибке.

Конкуренты — локальная процедурная симуляция. НДС и пошлины в справочнике стран
зарезервированы для будущих механик. Все данные принадлежат локальной игре;
общего рынка и серверного рейтинга нет.
